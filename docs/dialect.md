# 类 C++ 方言：与原生 C++ 的完整差异表 + 三款游戏 API

本仓库的三款编程对战游戏（炸弹人大赛、五子棋、赛车）都使用同一套**自研的类 C++ 解释器**，不是真正的 C++ 编译器。

## 各游戏总览

| 游戏 | 头文件 | 命名空间 | 可写变量 | 入口调用频率 | 详细文档 |
|---|---|---|---|---|---|
| 炸弹人大赛 | `#include<bomb.h>` | `bomb::` | `bomb::player_dir`、`bomb::player_bomb` | 每回合 1 次 | [bomb-api.md](./bomb-api.md) |
| 五子棋 | `#include<go.h>` | `go::` | `go::move_x`、`go::move_y` | 每回合 1 次 | [gomoku-api.md](./gomoku-api.md) |
| 赛车 | `#include<car.h>` | `car::` | `car::throttle`、`car::steer` | 每帧 1 次 | [racing-api.md](./racing-api.md) |

> 只能用**自己游戏**的头文件和命名空间。在五子棋里写 `bomb::` 或 `#include<bomb.h>` 会直接报错。

## 一、和原生 C++ 的全部差异对照表

这是**完整列表**，表中没有列出的特性一律不支持。

### 1. 编译与运行环境

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 1 | 执行方式 | 编译成机器码后运行 | 自研解释器逐句解释执行 | 没有编译产物 |
| 2 | 编译器 | gcc / clang / msvc | 无 | 编辑器里的「语法检查」是解释器的解析器 |
| 3 | 运行时间限制 | 无（除非题目限制） | **每次 `main()` 最多 50ms** | 超时本次调用作废 |
| 4 | 死循环保护 | 程序会挂住 | **约 20 万步上限**，触发后本次调用作废 | 不会卡死页面 |
| 5 | 内存管理 | 手动或智能指针 | **不需要也不能管理** | 无法申请/释放内存 |
| 6 | 多文件 / 链接 | 支持 | **不支持** | 只有一份代码 |
| 7 | 整数溢出 | 未定义行为 | **不溢出**（JS 双精度） | 超大数不建议 |
| 8 | 整除负数 | 向零取整（C++11 起） | **向零取整**（`Math.trunc`） | 与 C++ 一致 |
| 9 | 取模负数 | 符号跟随被除数 | **同 C++** | 与 C++ 一致 |

### 2. 预处理与头文件

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 10 | 头文件 | 任意 `#include<x>` | **只允许该游戏的唯一头文件** | 写 `iostream` 直接报错 |
| 11 | 头文件写法 | `<x>` 或 `"x"` | `<bomb.h>` / `"bomb.h"` 均可 | 也允许空格 |
| 12 | 缺少头文件 | 报错 | **报错**：第一行必须是该头文件 | 必须显式写出 |
| 13 | `#define` / 宏 | 支持 | **不支持** | 只识别 `#include` |
| 14 | `#pragma` 等指令 | 支持 | **不支持** | — |
| 15 | 条件编译 | `#if` / `#ifdef` | **不支持** | — |

### 3. 类型系统

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 16 | 可用类型 | 内置 + 自定义 | **只有** `int`、`bool`、`void`、`pair` | 四种，没有别的 |
| 17 | 浮点数 | `float` / `double` | **不支持** | 只有整数；速度、进度已放大成整数 |
| 18 | 字符 | `char` | **不支持** | 用 `int` |
| 19 | 字符串 | `std::string`、字面量 | **不支持** | 写 `"abc"` 或 `'a'` 报错 |
| 20 | 无符号 | `unsigned` / `size_t` | **不支持** | 全是普通 `int` |
| 21 | 指针 | `int*`、`&`、`new`/`delete` | **不支持** | 无解引用、无取地址、无动态分配 |
| 22 | 引用 | `int&` | **不支持** | 参数一律值传递 |
| 23 | 数组 | `int a[10]`、`vector` | **不能自己声明数组** | 只能对游戏给的数组用 `[]` 和 `.size()` |
| 24 | 结构体 / 类 | `struct` / `class` | **不支持** | 唯一复合类型是内置 `pair` |
| 25 | 枚举 | `enum` | **不支持** | 用 `int` 常量自己约定 |
| 26 | 类型别名 | `typedef` / `using` | **不支持** | — |
| 27 | 常量修饰 | `const` / `constexpr` | **不支持** | 只读性由 `::` 变量本身决定 |
| 28 | `auto` | 支持 | **不支持** | 必须写出类型 |
| 29 | `static` / `extern` / `inline` | 支持 | **不支持** | — |
| 30 | `sizeof` | 支持 | **不支持** | — |

### 4. 语法与语句

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 31 | `main` 签名 | `int main(...)` | **必须** `void main()` | 不能带参数、不能 `return 0` |
| 32 | `main` 调用次数 | 启动时 1 次 | **每回合/每帧 1 次** | 程序要在每次调用里决定动作 |
| 33 | `if` / `else` | 支持 | **支持** | — |
| 34 | `while` | 支持 | **支持** | — |
| 35 | `for` | 支持 | **支持** `for (int i = 0; i < n; i++)` | 三种写法都支持 |
| 36 | `do { } while` | 支持 | **不支持** | 用 `while` |
| 37 | `switch` / `case` | 支持 | **不支持** | 用 `if / else if` |
| 38 | `break` / `continue` | 支持 | **支持**（`for` / `while` 内） | — |
| 39 | `return` | 支持 | **支持**（`void` 函数可裸 `return;`） | 有返回值的函数必须 `return` |
| 40 | `goto` | 支持 | **不支持** | — |
| 41 | 三元运算符 | `a ? b : c` | **不支持** | 用 `if / else` |
| 42 | 块作用域 | 支持 | **支持** | `{}` 内声明的变量出了块就失效 |
| 43 | 变量重复定义 | 同作用域报错 | **同作用域报错**（「已经定义过了」） | 与 C++ 一致 |

### 5. 表达式与运算符

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 44 | 算术 | `+ - * / %` | **支持** | 只对 `int` |
| 45 | 比较 | `== != < <= > >=` | **支持** | `pair` 只支持 `==` / `!=` |
| 46 | 逻辑 | `&& \|\| !` | **支持** | 有短路求值 |
| 47 | 位运算 | `& \| ^ ~ << >>` | **不支持** | 注意：`&`、`\|` 单符号不能用 |
| 48 | 自增自减 | `i++`、`--i` | **支持**（前缀/后缀均可） | 不区分返回值差异 |
| 49 | 复合赋值 | `+= -= *= /= %=` | **支持** | — |
| 50 | 逗号表达式 | 支持 | **不支持** | 只能在参数列表/`pair()` 里用逗号 |
| 51 | 类型转换 | `(int)x`、`static_cast` | **不支持** | 没有隐式转换需求 |
| 52 | 成员访问 | `.` / `->` | **只有** `pair.first` / `pair.second` 和 `.size()` | — |
| 53 | 数组下标 | 支持 | **支持**，但**越界会直接报错** | 比 C++ 安全 |
| 54 | 运算符优先级 | 标准 | **与 C++ 一致** | `* / %` > `+ -` > 比较 > `&&` > `\|\|` |

### 6. 函数

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 55 | 自定义函数 | 支持 | **支持** | 返回 `int` / `bool` / `pair` / `void` |
| 56 | 递归 | 支持 | **支持**，深度上限 100 | 超过报错 |
| 57 | 函数重载 | 支持 | **不支持** | 同名函数报「重复定义」 |
| 58 | 默认参数 | 支持 | **不支持** | 参数个数必须一致 |
| 59 | 可变参数 | 支持 | **不支持** | — |
| 60 | 函数指针 | 支持 | **不支持** | — |
| 61 | lambda | 支持 | **不支持** | 写普通函数 |
| 62 | 模板 | 支持 | **不支持** | — |
| 63 | 内联 / 递归优化 | 有 | 无 | 性能足够 |

### 7. 语言特性

| # | 项目 | 原生 C++ | 本方言 | 说明 |
|---|---|---|---|---|
| 64 | 命名空间 | 任意 `namespace` | **只允许游戏规定的那一个** | 不能用 `using namespace` |
| 65 | 标准库 | `std::` 全部 | **完全没有** | 无 `cout`/`cin`/`vector`/`string`/`algorithm` |
| 66 | 输入输出 | `iostream` / `printf` | **完全没有** | 没有任何 I/O |
| 67 | 异常 | `try`/`catch`/`throw` | **不支持** | 出错即本次调用失败 |
| 68 | RAII / 析构 | 支持 | **不支持** | 没有对象 |
| 69 | 多线程 | `std::thread` | **不支持** | 单线程执行 |
| 70 | 全局变量 | 支持 | **支持**（跨调用保留状态） | 对整个对局有效 |
| 71 | 全局常量表 | 支持 | 支持（用全局 `int` 模拟） | 建议放全局数组外面 |

## 三、`pair` 类型

`pair` 是唯一的复合类型，表示「一对整数」，游戏里用来表示坐标。

| 操作 | 写法 | 结果 |
|---|---|---|
| 构造 | `pair p = pair(3, 5);` | `p.first == 3`，`p.second == 5` |
| 取第一个 | `p.first` | `int` |
| 取第二个 | `p.second` | `int` |
| 比较相等 | `p == q` | `bool`，逐字段比较 |
| 修改成员 | `p.first = 1;` | **报错**：不能修改 `pair` 成员 |
| 默认值 | `pair p;` | `pair(0, 0)` |

`pair` 数组（由游戏提供）：

```cpp
int n = bomb::enemy_pos.size();   // 长度
pair e = bomb::enemy_pos[0];      // 第 0 个
```

## 四、各游戏 API

每个游戏的完整 API（所有变量、函数、取值范围、常见错误）见单独文档：

### 炸弹人大赛 — [`bomb::`](./bomb-api.md)

可写：`bomb::player_dir`（0上 1右 2下 3左）、`bomb::player_bomb`（bool）

只读变量：`player_pos`、`other_pos`、`enemy_pos`、`bomb_pos`、`wall_pos`、`map_w`、`map_h`、`my_score`、`other_score`、`turn`、`is_alive`、`cooldown`

只读函数：`can_move(d)`、`is_wall(x,y)`、`dist(a,b)`、`in_danger(p)`、`can_retreat()`

### 五子棋 — [`go::`](./gomoku-api.md)

可写：`go::move_x`、`go::move_y`（0–14）

只读变量：`size`、`me`、`my_color`、`opp_color`、`turn`、`last_move`、`last_color`、`my_stones`、`opp_stones`、`illegal_count`

只读函数：`at(x,y)`、`is_empty(x,y)`、`in_board(x,y)`、`count_line(x,y)`

### 赛车 — [`car::`](./racing-api.md)

可写：`car::throttle`（0–100）、`car::steer`（-100–100）

只读变量：`my_x`、`my_y`、`my_speed`、`my_progress`、`opp_progress`、`opp_x`、`opp_y`、`track_width`、`track_left`、`track_right`、`center_offset`、`off_track`、`tick`

只读函数：`center_ahead(d)`、`boundary_ahead(d)`、`distance_to_center()`、`abs(v)`、`max(a,b)`、`min(a,b)`

## 五、通用约定

- **坐标**：`(x, y)`，`x` 向右增大，`y` 向下增大（与屏幕一致）。
- **方向**：`0 = 上`，`1 = 右`，`2 = 下`，`3 = 左`。
- **数组越界**：`arr[i]` 必须满足 `0 <= i < arr.size()`，否则报错。
- **只读 / 可写**：每款游戏**可写变量只有两个**，写其余变量会报「只读」错误。
- **错误处理**：任何错误（语法、类型、越界、超时、只读）都会让**本次调用作废**：炸弹人不动、五子棋弃权、赛车保持上次输入，对局继续。
- **性能建议**：每次调用只有 50ms，避免多层嵌套大循环；需要缓存的地图信息用全局变量在第一次调用时算好。
